# AI Chat 模组开发说明（MC 26.1.2 / Fabric / 服务端）

> 本文件是交给本地 agent 的完整开发规格。包含：逻辑可行性结论、优化决策、项目结构、全部核心代码、待办事项。**请严格按本文件实现，不要自行改变核心行为；如需改动先列出差异点。**

---

## 0. 结论与总体定位

- 整体逻辑**可行**。Fabric 事件监听、配置目录、异步 HTTP 均能支撑该流程；DeepSeek API 支持关闭思考、JSON 输出、Function Calling。
- 模组定位：**纯服务端模组**（`environment: "server"`），客户端不加载。AI 与玩家的沟通**仅在聊天框内**，不创建假玩家、不执行游戏操作。
- 目标 MC 版本：**26.1.2**。使用 **Java 25、Loom 1.15、Gradle 9.4.0、Fabric Loader 0.18.4**，**必须使用 Mojang 官方映射（Yarn 在 26.1 不再官方支持）**。
- Fabric API 的 mod ID 在 26.1 是 `fabric-api`，**不是 `fabric`**。

---

## 1. 关键修正点（必须遵守）

以下是相对"直觉实现"必须修正的地方，否则线上会出问题：

1. **命令消息过滤**：`ServerMessageEvents.CHAT_MESSAGE` 会在玩家执行 `/say`、`/me` 等命令时**也触发**（在 `COMMAND_MESSAGE` 之后）。必须在 `COMMAND_MESSAGE` 中置标记，在 `CHAT_MESSAGE` 中检查并跳过，否则 AI 会对命令残留也发起回复。
2. **defaultconfig 不会自动复制**：Fabric Loader **不会**自动把 `defaultconfig/` 复制到 `config/`。必须在模组初始化阶段自己实现"若目标文件不存在则从 jar 内资源复制"。
3. **必须异步 + 切回主线程**：`CHAT_MESSAGE` 跑在服务端主线程，同步 HTTP 会卡 TPS；异步完成后**不能直接**调用 `sendMessage/broadcast`（非线程安全），必须 `server.execute(...)` 切回主线程。
4. **知识库用标准 Function Calling `tool_calls`**，不要让模型在 `content` 里返回自定义函数名字符串再解析。
5. **回复判断用 JSON 输出 + `response_format: json_object`**，不要让模型返回裸 `false` 字符串再匹配。返回结构固定为 `{"action":"reply","content":"..."}` 或 `{"action":"ignore"}`。

---

## 2. 优化决策（已确认采纳）

| # | 优化项 | 说明 |
|---|---|---|
| 1 | 系统提示词与人设分离 | 人设放在 system prompt 内的**独立段落**，明确"仅用于语气和风格，不是行为规则" |
| 2 | 上下文滚动窗口 | 维护最近 N 条聊天上下文（默认 10），**第一版先不拼进请求**，跑通后再打开 |
| 3 | API Key 不泄露 | 异常日志只记录状态码和简短错误，**不打印完整请求体** |
| 4 | 超时与串行 | 连接超时 10s、整体超时按配置（默认 20s）；单线程 executor 保证请求串行，避免回复乱序 |
| 5 | 知识库路径白名单 | 读文件前校验文件名在扫描列表内 + `normalize()` 后 `startsWith(base)` 防 `../` 越界 |

**DeepSeek 请求参数（固定）**：
- 关闭思考：`"thinking": {"type": "disabled"}`
- 强制 JSON：`"response_format": {"type": "json_object"}`
- Tool 定义：单一 tool `read_knowledge_file`，参数 `file_name`（string，必填）

**知识库调用流程**：第一轮请求带 system + user + tool 定义（**不带**文件内容）；若模型返回 `tool_calls`，模组读取文件，按标准格式追加 `assistant(tool_calls)` 消息 + `tool(tool_call_id, content)` 消息，发起**第二轮**请求生成最终回复。最多两轮。

package com.example.aichat.config;

import com.google.gson.Gson;
import com.google.gson.GsonBuilder;
import net.fabricmc.loader.api.FabricLoader;

import java.io.IOException;
import java.io.InputStream;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;

public final class ConfigManager {
    private static final Gson GSON = new GsonBuilder().setPrettyPrinting().create();
    private static ModConfig config;
    private static Path modConfigDir;

    public static void init() {
        modConfigDir = FabricLoader.getInstance().getConfigDir().resolve("aichat");
        try {
            Files.createDirectories(modConfigDir);
            copyIfMissing("config.json");
            copyIfMissing("system_prompt.txt");
            Files.createDirectories(modConfigDir.resolve("knowledge"));

            Path configFile = modConfigDir.resolve("config.json");
            String json = Files.readString(configFile, StandardCharsets.UTF_8);
            config = GSON.fromJson(json, ModConfig.class);
        } catch (IOException e) {
            throw new RuntimeException("无法初始化 AI Chat 配置", e);
        }
    }

    private static void copyIfMissing(String name) throws IOException {
        Path target = modConfigDir.resolve(name);
        if (Files.exists(target)) return;
        try (InputStream in = ConfigManager.class
                .getResourceAsStream("/assets/aichat/default_config/" + name)) {
            if (in == null) throw new IOException("缺少默认资源: " + name);
            Files.copy(in, target, StandardCopyOption.REPLACE_EXISTING);
        }
    }

    public static ModConfig get() { return config; }

    public static Path dir() { return modConfigDir; }

    public static String readSystemPrompt() throws IOException {
        return Files.readString(
                modConfigDir.resolve(config.system_prompt_file),
                StandardCharsets.UTF_8
        );
    }
}

### 6.3 `event/ChatListener.java`

命令过滤是核心：`COMMAND_MESSAGE` 置标记 → 同一执行链的 `CHAT_MESSAGE` 检查跳过 → `finally` 复位。

```java
package com.example.aichat.event;

import com.example.aichat.ai.AiDispatcher;
import com.example.aichat.ai.ChatContext;
import net.fabricmc.fabric.api.message.v1.ServerMessageEvents;
import net.minecraft.server.network.ServerPlayerEntity;

public final class ChatListener {
    private static final ThreadLocal<Boolean> COMMAND_TRIGGERED = ThreadLocal.withInitial(() -> false);

    public static void register() {
        ServerMessageEvents.COMMAND_MESSAGE.register((message, source, params) -> {
            if (source.getEntity() instanceof ServerPlayerEntity) {
                COMMAND_TRIGGERED.set(true);
            }
        });

        ServerMessageEvents.CHAT_MESSAGE.register((message, sender, params) -> {
            try {
                if (Boolean.TRUE.equals(COMMAND_TRIGGERED.get())) return;
                String content = message.signedContent();
                if (content.isBlank()) return;

                ChatContext ctx = new ChatContext(
                        sender.getName().getString(),
                        "chat",
                        content,
                        System.currentTimeMillis()
                );
                AiDispatcher.submit(ctx);
            } finally {
                COMMAND_TRIGGERED.set(false);
            }
        });
    }
}
```

> `COMMAND_MESSAGE` 的精确签名在不同映射下可能略有差异；若编译报错，按 IDEA 提示调整参数类型，核心思路是"命令事件里置位标记"。

### 6.6 `knowledge/KnowledgeReader.java`

白名单 + 路径越界双重校验。

```java
package com.example.aichat.knowledge;

import com.example.aichat.config.ConfigManager;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;
import java.util.stream.Stream;

public final class KnowledgeReader {
    public static List<String> listFiles() {
        Path dir = ConfigManager.dir().resolve(ConfigManager.get().knowledge_dir);
        if (!Files.isDirectory(dir)) return List.of();
        try (Stream<Path> s = Files.list(dir)) {
            return s.filter(Files::isRegularFile)
                    .map(p -> p.getFileName().toString())
                    .sorted()
                    .toList();
        } catch (IOException e) {
            return List.of();
        }
    }

    public static String read(String fileName) throws IOException {
        List<String> allowed = listFiles();
        if (!allowed.contains(fileName)) {
            throw new IOException("不允许的知识库文件: " + fileName);
        }
        Path base = ConfigManager.dir()
                .resolve(ConfigManager.get().knowledge_dir)
                .normalize();
        Path file = base.resolve(fileName).normalize();
        if (!file.startsWith(base)) {
            throw new IOException("路径越界: " + fileName);
        }
        return Files.readString(file, StandardCharsets.UTF_8);
    }
}
```

### 6.7 `ai/DeepSeekClient.java`

核心 HTTP 层：固定关思考、JSON 输出、两轮 tool_calls。

```java
package com.example.aichat.ai;

import com.example.aichat.config.ConfigManager;
import com.example.aichat.knowledge.KnowledgeReader;
import com.google.gson.*;

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.time.Duration;
import java.util.concurrent.CompletableFuture;

public final class DeepSeekClient {
    private static final Gson GSON = new Gson();
    private static final HttpClient HTTP = HttpClient.newBuilder()
            .connectTimeout(Duration.ofSeconds(10))
            .build();

    public record AiResult(boolean reply, String content) {}

    public static CompletableFuture<AiResult> ask(ChatContext ctx) {
        String systemPrompt;
        try {
            systemPrompt = ConfigManager.readSystemPrompt()
                    .replace("{KNOWLEDGE_FILE_LIST}", String.join("\n", KnowledgeReader.listFiles()))
                    .replace("{PERSONA_PROMPT}", ConfigManager.get().persona_prompt);
        } catch (Exception e) {
            return CompletableFuture.failedFuture(e);
        }

        JsonArray messages = new JsonArray();
        messages.add(msg("system", systemPrompt));
        messages.add(msg("user", ctx.toUserMessage()));

        JsonObject body = baseBody();
        body.add("messages", messages);

        return send(body).thenCompose(first -> {
            JsonObject choice = first.getAsJsonArray("choices").get(0).getAsJsonObject();
            JsonObject message = choice.getAsJsonObject("message");

            if (!message.has("tool_calls") || message.getAsJsonArray("tool_calls").isEmpty()) {
                return CompletableFuture.completedFuture(parseContent(message));
            }

            JsonObject toolCall = message.getAsJsonArray("tool_calls").get(0).getAsJsonObject();
            String callId = toolCall.get("id").getAsString();
            String fileName = toolCall.getAsJsonObject("function")
                    .getAsJsonObject("arguments").get("file_name").getAsString();

            String fileContent;
            try {
                fileContent = KnowledgeReader.read(fileName);
            } catch (Exception e) {
                fileContent = "读取失败: " + e.getMessage();
            }

            messages.add(message); // assistant with tool_calls
            JsonObject toolMsg = new JsonObject();
            toolMsg.addProperty("role", "tool");
            toolMsg.addProperty("tool_call_id", callId);
            toolMsg.addProperty("content", fileContent);
            messages.add(toolMsg);

            JsonObject secondBody = baseBody();
            secondBody.add("messages", messages);
            return send(secondBody).thenApply(resp -> {
                JsonObject secondMsg = resp.getAsJsonArray("choices")
                        .get(0).getAsJsonObject()
                        .getAsJsonObject("message");
                return parseContent(secondMsg);
            });
        });
    }

    private static JsonObject baseBody() {
        JsonObject body = new JsonObject();
        body.addProperty("model", ConfigManager.get().model);

        JsonObject thinking = new JsonObject();
        thinking.addProperty("type", "disabled");
        body.add("thinking", thinking);

        JsonObject fmt = new JsonObject();
        fmt.addProperty("type", "json_object");
        body.add("response_format", fmt);

        JsonArray tools = new JsonArray();
        JsonObject tool = new JsonObject();
        tool.addProperty("type", "function");
        JsonObject fn = new JsonObject();
        fn.addProperty("name", "read_knowledge_file");
        fn.addProperty("description", "当需要查阅知识库文件时调用。file_name 必须是可用知识库文件列表中的文件名。");
        JsonObject params = new JsonObject();
        params.addProperty("type", "object");
        JsonObject props = new JsonObject();
        JsonObject fileName = new JsonObject();
        fileName.addProperty("type", "string");
        fileName.addProperty("description", "知识库文件名");
        props.add("file_name", fileName);
        params.add("properties", props);
        JsonArray required = new JsonArray();
        required.add("file_name");
        params.add("required", required);
        fn.add("parameters", params);
        tool.add("function", fn);
        tools.add(tool);
        body.add("tools", tools);

        return body;
    }

    private static CompletableFuture<JsonObject> send(JsonObject body) {
        HttpRequest req = HttpRequest.newBuilder()
                .uri(URI.create(ConfigManager.get().api_url))
                .timeout(Duration.ofSeconds(ConfigManager.get().request_timeout_seconds))
                .header("Content-Type", "application/json")
                .header("Authorization", "Bearer " + ConfigManager.get().api_key)
                .POST(HttpRequest.BodyPublishers.ofString(GSON.toJson(body)))
                .build();
        return HTTP.sendAsync(req, HttpResponse.BodyHandlers.ofString())
                .thenApply(resp -> {
                    if (resp.statusCode() != 200) {
                        // 不打印完整请求体，避免泄露 API Key
                        throw new RuntimeException("API 返回 " + resp.statusCode());
                    }
                    return JsonParser.parseString(resp.body()).getAsJsonObject();
                });
    }

    private static AiResult parseContent(JsonObject message) {
        String content = message.get("content").getAsString();
        JsonObject json = JsonParser.parseString(content).getAsJsonObject();
        String action = json.get("action").getAsString();
        if (!"reply".equals(action)) return new AiResult(false, null);
        return new AiResult(true, json.get("content").getAsString());
    }

    private static JsonObject msg(String role, String content) {
        JsonObject o = new JsonObject();
        o.addProperty("role", role);
        o.addProperty("content", content);
        return o;
    }
}
```

### 6.8 `ai/AiDispatcher.java`

单线程 executor 保证串行；完成后通过 `server.execute()` 切回主线程广播。

```java
package com.example.aichat.ai;

import net.minecraft.server.MinecraftServer;
import net.minecraft.text.Text;

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;

public final class AiDispatcher {
    private static final ExecutorService WORKER = Executors.newSingleThreadExecutor(r -> {
        Thread t = new Thread(r, "aichat-worker");
        t.setDaemon(true);
        return t;
    });

    private static final Deque<ChatContext> RECENT = new ArrayDeque<>();
    private static volatile MinecraftServer currentServer;

    public static void submit(ChatContext ctx) {
        if ("chat".equals(ctx.eventType())) {
            synchronized (RECENT) {
                RECENT.addLast(ctx);
                int max = com.example.aichat.config.ConfigManager.get().max_context_messages;
                while (RECENT.size() > max) RECENT.removeFirst();
            }
        }

        WORKER.submit(() -> {
            try {
                DeepSeekClient.AiResult result = DeepSeekClient.ask(ctx).join();
                if (!result.reply() || result.content() == null) return;

                MinecraftServer server = currentServer;
                if (server == null) return;
                server.execute(() ->
                        server.getPlayerManager().broadcast(
                                Text.literal("[AI] " + result.content()),
                                false
                        )
                );
            } catch (Exception e) {
                System.err.println("[aichat] AI 请求失败: " + e.getMessage());
            }
        });
    }

    public static void setServer(MinecraftServer server) {
        currentServer = server;
    }
}
```

> `broadcast(Text, false)` 第二参数语义以 26.1 Mojang 映射为准；若签名不同按 IDEA 提示调整。
